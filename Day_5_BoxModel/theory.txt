CSS BOX MODEL - 
========================================

1. WHAT IS THE CSS BOX MODEL?
-----------------------------
The CSS Box Model describes how every HTML element is represented as a
rectangular box in the browser.

Every box consists of four layers:

1. Content
2. Padding
3. Border
4. Margin

Order from inside to outside:

Content -> Padding -> Border -> Margin


2. CONTENT
----------
WHAT:
The content is the actual data inside an HTML element, such as text,
an image, or other child elements.

CSS properties:
    width
    height

Example:
    .box {
        width: 200px;
        height: 100px;
    }

By default, width and height apply to the content area when
box-sizing: content-box is used.

Note:
The final visible size can be larger than the specified width and height
because padding and borders may be added.


3. PADDING
----------
WHAT:
Padding is the space between the content and the border.

WHY:
It creates breathing space inside an element, so content does not touch
the border.

Example:
    .box {
        padding: 20px;
    }

This applies 20px padding to all four sides.

Individual padding properties:
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 15px;
    padding-left: 25px;

Shorthand syntax:

A. One value:
    padding: 10px;
    /* Top, right, bottom, left = 10px */

B. Two values:
    padding: 10px 20px;
    /* Top/bottom = 10px; left/right = 20px */

C. Three values:
    padding: 10px 20px 30px;
    /* Top = 10px; left/right = 20px; bottom = 30px */

D. Four values:
    padding: 10px 20px 30px 40px;
    /* Top, right, bottom, left (clockwise) */

Important:
Padding is inside the border.
Padding cannot have negative values.
Padding is included in the element's size under content-box sizing,
but it is included within the specified width/height under border-box sizing.


4. BORDER
---------
WHAT:
The border surrounds the content and padding.

WHY:
It can visually separate an element from its surroundings.

Main border properties:
    border-width
    border-style
    border-color

Example:
    .box {
        border-width: 2px;
        border-style: solid;
        border-color: black;
    }

Shorthand:
    border: 2px solid black;

The border shorthand generally uses:
    border: width style color;

Common border styles:
    solid
    dashed
    dotted
    double
    groove
    ridge
    inset
    outset
    none
    hidden

Side-specific border properties:
    border-top: 2px solid red;
    border-right: 3px dashed blue;
    border-bottom: 1px solid green;
    border-left: 4px dotted orange;

Other useful border properties:
    border-radius: 10px;
    /* Rounds the corners */

    border-radius: 50%;
    /* Can make a square element circular */

    border-top-left-radius: 10px;
    /* Rounds only the top-left corner */

Important:
A border has width, but it also needs a visible style to appear.
For example, border: 2px solid black; creates a visible border.


5. MARGIN
---------
WHAT:
Margin is the space outside an element's border.

WHY:
It creates space between an element and neighboring elements.

Example:
    .box {
        margin: 20px;
    }

This applies 20px margin to all four sides.

Individual margin properties:
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 15px;
    margin-left: 25px;

Margin shorthand follows the same one-, two-, three-, and four-value
pattern as padding.

Important differences:
- Padding creates space inside the border.
- Margin creates space outside the border.
- Background color normally covers the content and padding, and the
  border is painted separately. The margin area is transparent.
- Margins can be negative; padding cannot.
- Horizontal margins can be set to auto to help center a block with a
  specified width.

Example: center a block element horizontally
    .container {
        width: 600px;
        margin-left: auto;
        margin-right: auto;
    }

Shorthand:
    margin: 0 auto;

This centers the element horizontally when it has an appropriate
specified width and available space.


6. BOX-SIZING
-------------
WHAT:
The box-sizing property controls how the browser calculates an
element's width and height.

Two important values:
    content-box
    border-box


A. box-sizing: content-box (default)
------------------------------------
The specified width and height apply only to the content.

Total width =
    width
    + left padding + right padding
    + left border + right border

Total height =
    height
    + top padding + bottom padding
    + top border + bottom border

Example:
    .box {
        width: 200px;
        height: 100px;
        padding: 20px;
        border: 5px solid black;
    }

Calculation:
    Total width  = 200 + 20 + 20 + 5 + 5
                 = 250px

    Total height = 100 + 20 + 20 + 5 + 5
                 = 150px

If horizontal margins are 10px on both sides:
    Space occupied horizontally, including margins
                 = 250 + 10 + 10
                 = 270px

If vertical margins are 10px on both sides:
    Space occupied vertically, including margins
                 = 150 + 10 + 10
                 = 170px

Note:
Margins are not part of the element's border-box dimensions. They are
added when calculating the space occupied including margins.


B. box-sizing: border-box
-------------------------
The specified width and height include the content, padding, and border.

Example:
    .box {
        box-sizing: border-box;
        width: 200px;
        height: 100px;
        padding: 20px;
        border: 5px solid black;
    }

Calculation:
    Total border-box width  = 200px
    Total border-box height = 100px

The browser reduces the content area to make room for padding and border.

Content width:
    200 - 20 - 20 - 5 - 5 = 150px

Content height:
    100 - 20 - 20 - 5 - 5 = 50px

Margins are still outside the border box.

Why developers often use border-box:
- Layout calculations are easier.
- Elements are less likely to become wider than expected.
- It is useful for responsive layouts and grids.


C. Common global reset
----------------------
Many projects use:

    * {
        box-sizing: border-box;
    }

This applies border-box sizing to every element.

A common alternative also includes pseudo-elements:

    *,
    *::before,
    *::after {
        box-sizing: border-box;
    }

This helps keep pseudo-elements such as ::before and ::after consistent
with the same sizing rule.


7. TOTAL WIDTH AND HEIGHT FORMULAS
----------------------------------
For a normal element using content-box:

Total border-box width =
    width + left padding + right padding
          + left border + right border

Total border-box height =
    height + top padding + bottom padding
           + top border + bottom border

Space occupied horizontally, including margins =
    total border-box width + left margin + right margin

Space occupied vertically, including margins =
    total border-box height + top margin + bottom margin

For border-box:
    The declared width and height already include content, padding,
    and border. Add margins only if calculating the space occupied
    including margins.

Important:
These formulas assume ordinary CSS box sizing and do not account for
special layout behavior such as flex/grid sizing, transforms, or
collapsing margins between elements.


8. MARGIN COLLAPSING
--------------------
WHAT:
Margin collapsing happens when certain vertical margins of block-level
elements combine into one margin instead of adding together.

It mainly applies to vertical margins in normal block flow.
Horizontal margins do not collapse.

Example 1: Two adjacent block elements

HTML:
    <div class="first">First box</div>
    <div class="second">Second box</div>

CSS:
    .first {
        margin-bottom: 30px;
    }

    .second {
        margin-top: 20px;
    }

Expected gap:
    30px + 20px = 50px

Actual gap in normal block flow:
    30px

Why?
The positive vertical margins collapse to the larger margin, not their
sum.

Example 2: One positive and one negative margin
    margin-bottom: 30px;
    margin-top: -10px;

The resulting collapsed margin is generally 20px.

Example 3: Two negative margins
    margin-bottom: -20px;
    margin-top: -10px;

The resulting collapsed margin is generally -20px (the more negative
margin).

Important cases where vertical margins may collapse:
- Between adjacent block-level siblings in normal flow.
- Between a parent and its first or last in-flow block child, when no
  border, padding, inline content, or other separating condition
  prevents it.
- Certain empty block elements can have their top and bottom margins
  collapse.

Margins generally do not collapse:
- Inside a flex container between flex items.
- Inside a grid container between grid items.
- Between absolutely positioned elements.
- Between floated elements.
- When a block establishes a new block formatting context, such as
  with overflow: auto or display: flow-root, in relevant parent-child
  cases.

Ways to prevent parent-child margin collapsing can include:
    border: 1px solid transparent;
    padding-top: 1px;
    display: flow-root;
    overflow: auto;

Choose a method based on the layout. Do not add arbitrary borders or
padding without understanding their visual and layout effects.

Remember:
Margin collapsing does not mean margins always collapse. It happens
only in specific layout situations, mainly involving vertical margins
of block boxes in normal flow.


9. MARGIN AUTO VS PADDING
-------------------------
Example:
    .card {
        width: 300px;
        padding: 20px;
        margin: 0 auto;
        border: 1px solid black;
    }

Here:
- Padding gives space between the card content and its border.
- margin: 0 auto centers the card horizontally when there is available
  space and the element's width allows centering.

For a flex container:
    .container {
        display: flex;
        justify-content: center;
    }

This centers flex items along the main axis. It is a layout technique,
not the same as margin collapsing.


10. PRACTICAL EXAMPLE
---------------------
HTML:
    <div class="card">
        <h2>CSS Box Model</h2>
        <p>Learning content, padding, border, and margin.</p>
    </div>

CSS:
    * {
        box-sizing: border-box;
    }

    .card {
        width: 300px;
        padding: 20px;
        border: 2px solid steelblue;
        margin: 30px auto;
        border-radius: 8px;
        background-color: #f2f7ff;
    }

Explanation:
- width: 300px sets the total border-box width because border-box is used.
- padding: 20px creates internal space.
- border creates the visible outline.
- margin: 30px auto adds vertical space and centers the card horizontally.
- border-radius rounds the corners.
- background-color colors the content and padding area.


11. COMMON STUDENT MISTAKES
---------------------------
1. Thinking padding and margin are the same.
   Correction: Padding is inside the border; margin is outside.

2. Forgetting that content-box is the default.
   Correction: With content-box, padding and border increase the final
   border-box size beyond the declared width and height.

3. Adding margins to the content-box formula but calling it the
   element's width.
   Correction: Margins are outside the border box. Include them only
   when calculating the space occupied including margins.

4. Assuming vertical margins always add together.
   Correction: Some vertical margins collapse. Check the layout context.

5. Assuming border-width alone always shows a border.
   Correction: Set a visible border-style, such as solid.

6. Assuming margin: auto always centers every element.
   Correction: Horizontal centering with margin: 0 auto generally
   requires a block-level box with an appropriate width and available
   horizontal space.

7. Confusing the CSS width property with the size shown on screen.
   Correction: Consider box-sizing, padding, border, margins, and the
   surrounding layout.


12. QUICK REVISION
------------------
Content  = actual content
Padding  = space inside the border
Border   = outline around content and padding
Margin   = space outside the border

content-box:
    Declared width/height = content area only

border-box:
    Declared width/height = content + padding + border

Margin collapsing:
    Certain vertical margins in normal block flow combine instead of
    simply adding together.

Common sizing rule:
    *,
    *::before,
    *::after {
        box-sizing: border-box;
    }

Remember the order:
    Content -> Padding -> Border -> Margin
