CSS COLOR THEORY - DETAILED NOTES
================================

1. WHAT IS COLOR IN CSS?
------------------------
WHAT:
CSS color values define the colors of text, backgrounds, borders, shadows, and other visual elements on a webpage.

WHY:
- Improves readability.
- Creates visual hierarchy.
- Communicates meaning (for example, red for errors and green for success).
- Maintains consistent branding.

WHERE:
Common CSS properties that accept colors:
- color                  -> Text color
- background-color       -> Background color
- border-color           -> Border color
- outline-color          -> Outline color
- text-decoration-color  -> Text decoration color
- box-shadow             -> Shadow color
- fill and stroke        -> SVG graphics

HOW:
.heading {
    color: blue;
}

.card {
    background-color: #f0f8ff;
    border-color: rgb(0, 100, 200);
}

.button {
    background-color: hsl(220, 80%, 50%);
}


2. SIX TRADITIONAL WAYS TO SPECIFY COLORS
-----------------------------------------
1. Color names  -> color: red;
2. Hexadecimal  -> color: #CE5679;
3. RGB          -> color: rgb(46, 139, 87);
4. RGBA         -> color: rgba(46, 139, 87, 0.5);
5. HSL          -> color: hsl(280, 70%, 50%);
6. HSLA         -> color: hsla(280, 70%, 50%, 0.5);

IMPORTANT:
These are six traditional teaching categories. Modern CSS also supports alpha
(transparency) in hexadecimal, RGB, and HSL notation. The rgba() and hsla()
functions are still valid and are aliases of rgb() and hsl() with alpha.


3. COLOR NAMES
--------------
WHAT:
A color name is a predefined keyword recognized by CSS.

SYNTAX:
selector {
    property: color-name;
}

EXAMPLE:
.heading {
    color: red;
}

.message {
    color: darkgreen;
}

body {
    background-color: lightyellow;
}

COMMON COLOR NAMES:
red, blue, green, pink, black, white, orange, purple, gold, gray, navy, coral.

ADVANTAGES:
- Easy to understand and remember.
- Useful for beginner examples.
- Makes code readable.

LIMITATIONS:
- There is not a convenient name for every possible color.
- Exact brand colors are usually better represented with hex, RGB, or HSL.

REAL-TIME EXAMPLE:
Use red for a simple error message in practice. In a real project, a specific
design-system color may be used to keep branding consistent.


4. HEXADECIMAL COLOR VALUES
---------------------------
WHAT:
Hexadecimal (hex) is a base-16 number system. It uses:
0-9 and A-F

CSS hexadecimal colors represent red, green, and blue channel values.

SYNTAX:
#RRGGBB

MEANING:
RR -> Red
GG -> Green
BB -> Blue

Each two-digit channel ranges from 00 to FF:
00 = decimal 0
FF = decimal 255

THREE-DIGIT HEX:
#RGB

Each digit is repeated to form the six-digit version.
Example:
#F0A becomes #FF00AA

SIX-DIGIT HEX:
#RRGGBB

Example:
#CE5679

EXAMPLE:
.red {
    color: #ff0000;
}

.green {
    color: #008000;
}

.blue {
    color: #0000ff;
}

.custom {
    color: #ce5679;
}

HOW DOES #FF0000 WORK?
Red   = FF = 255
Green = 00 = 0
Blue  = 00 = 0

Red is at maximum intensity, while green and blue are zero. The result is red.

HEX WITH TRANSPARENCY:
CSS supports:
- #RGBA       -> 4-digit shorthand
- #RRGGBBAA   -> 8-digit format

Example:
.transparent-red {
    color: #ff000080;
}

The final 80 represents approximately 50% alpha.

IMPORTANT CORRECTION:
Hex colors can contain 3, 4, 6, or 8 digits after #.
In #RRGGBBAA, AA is the alpha channel and comes last.


5. RGB - RED, GREEN, BLUE
-------------------------
WHAT:
RGB is a color model that creates colors by combining red, green, and blue light.

SYNTAX:
color: rgb(red, green, blue);

In the traditional numeric form, each channel ranges from 0 to 255.

VALUES:
0   -> No intensity for that channel
128 -> Medium intensity
255 -> Maximum intensity

EXAMPLES:
.red {
    color: rgb(255, 0, 0);
}

.green {
    color: rgb(0, 255, 0);
}

.blue {
    color: rgb(0, 0, 255);
}

.white {
    color: rgb(255, 255, 255);
}

.black {
    color: rgb(0, 0, 0);
}

.yellow {
    color: rgb(255, 255, 0);
}

HOW DOES RGB WORK?
RGB is an additive color model. It combines light, not paint.

Red + Green       = Yellow
Red + Blue        = Magenta
Green + Blue      = Cyan
Red + Green + Blue at maximum = White
All channels at zero           = Black

WHERE IS RGB USED?
- Generating colors dynamically with JavaScript.
- Creating charts and visualizations.
- Adjusting colors in browser developer tools.
- Building custom themes and interfaces.

DEVELOPER TIP:
RGB is useful when controlling each color channel numerically. Hexadecimal
and RGB can represent the same standard sRGB color.


6. RGBA - RGB WITH ALPHA
------------------------
WHAT:
RGBA adds an alpha channel to RGB. Alpha controls the opacity of the color.

SYNTAX:
color: rgba(red, green, blue, alpha);

ALPHA VALUES:
1   -> Fully opaque
0.5 -> 50% opacity
0   -> Fully transparent

The valid alpha range is 0 to 1, including both endpoints. It is not restricted
to 0.1 to 1.

EXAMPLE:
.box1 {
    background-color: rgba(255, 0, 0, 1);
}

.box2 {
    background-color: rgba(255, 0, 0, 0.5);
}

.box3 {
    background-color: rgba(255, 0, 0, 0);
}

REAL-TIME EXAMPLE - MODAL OVERLAY:
.modal-overlay {
    position: fixed;
    inset: 0;
    background-color: rgba(0, 0, 0, 0.6);
}

This creates a black overlay with 60% opacity. The page behind it remains
partially visible.

ALPHA VS OPACITY PROPERTY:
Using alpha in a background color:
.card {
    background-color: rgba(0, 0, 0, 0.5);
}
Only the background color is transparent; the text inside remains opaque.

Using opacity:
.card {
    opacity: 0.5;
}
The entire element, including its text and children, becomes translucent.

COMMON MISTAKE:
Use alpha in the background color when you want a transparent background
but readable text.


7. HSL - HUE, SATURATION, LIGHTNESS
-----------------------------------
WHAT:
HSL represents a color using hue, saturation, and lightness.

SYNTAX:
color: hsl(hue, saturation, lightness);

A. HUE
Hue identifies the color family on a color wheel. It is measured in degrees.

Approximate hue values:
0 degrees   -> Red
60 degrees  -> Yellow
120 degrees -> Green
180 degrees -> Cyan
240 degrees -> Blue
300 degrees -> Magenta
360 degrees -> Red again

Hue wraps around the color wheel. Therefore, 0 degrees and 360 degrees
represent the same hue.

B. SATURATION
Saturation controls how vivid or muted a color is. It is expressed as a
percentage.

0%   -> No saturation; a shade of gray
50%  -> Partially saturated
100% -> Fully saturated for the selected hue

C. LIGHTNESS
Lightness controls how light or dark the color appears. It is expressed as
a percentage.

0%   -> Black
50%  -> The selected hue at that saturation
100% -> White

At 100% lightness, the result is white regardless of hue or saturation.

EXAMPLES:
.blue {
    color: hsl(240, 100%, 50%);
}

.light-blue {
    color: hsl(240, 100%, 80%);
}

.dark-blue {
    color: hsl(240, 100%, 20%);
}

.gray {
    color: hsl(0, 0%, 50%);
}

.red {
    color: hsl(0, 100%, 50%);
}

WHY IS HSL USEFUL?
Imagine a website that uses the same brand color for buttons, hover states,
borders, and backgrounds. With HSL, you can keep the hue and saturation
consistent while changing lightness to create related shades.

EXAMPLE - BUTTON STATES:
:root {
    --brand-hue: 220;
}

.button {
    background-color: hsl(var(--brand-hue), 80%, 50%);
}

.button:hover {
    background-color: hsl(var(--brand-hue), 80%, 40%);
}

.button:active {
    background-color: hsl(var(--brand-hue), 80%, 30%);
}

IMPORTANT DISTINCTION:
Saturation is not the same as lightness.
- Saturation controls vividness.
- Lightness controls the light-to-dark level.

A color can be highly saturated and dark, or highly saturated and light.


8. HSLA - HSL WITH ALPHA
------------------------
WHAT:
HSLA extends HSL by adding an alpha channel for transparency.

SYNTAX:
color: hsla(hue, saturation, lightness, alpha);

The first three values work like HSL. Alpha controls opacity from 0 to 1.

EXAMPLE:
.box1 {
    background-color: hsla(210, 100%, 50%, 1);
}

.box2 {
    background-color: hsla(210, 100%, 50%, 0.5);
}

.box3 {
    background-color: hsla(210, 100%, 50%, 0.2);
}

All three use the same blue hue, saturation, and lightness. Only alpha changes.

REAL-TIME EXAMPLE:
.notification {
    background-color: hsla(145, 60%, 35%, 0.15);
    border: 1px solid hsl(145, 60%, 35%);
    color: hsl(145, 60%, 20%);
}

This creates a subtle green background, a stronger green border, and dark green
text.


9. RGB VS HSL
-------------
RGB:
- Uses red, green, and blue channels.
- Traditional numeric channels range from 0 to 255.
- Useful when controlling channel values directly.

HSL:
- Uses hue, saturation, and lightness.
- Hue uses degrees; saturation and lightness use percentages.
- Useful for creating related shades and theme colors.

RGBA:
- RGB plus alpha.

HSLA:
- HSL plus alpha.

MODERN CSS ALPHA SYNTAX:
Modern CSS also supports slash notation.

RGB:
background-color: rgb(255 0 0 / 50%);

HSL:
background-color: hsl(0 100% 50% / 50%);

The rgba() and hsla() functions remain valid.


10. CSS GRADIENTS
-----------------
WHAT:
A gradient creates a smooth transition between two or more colors.

Gradients are usually applied using the background or background-image
property.

THREE MAIN TYPES:
1. Linear gradient
2. Radial gradient
3. Conic gradient

A. LINEAR GRADIENT
Transitions between colors along a straight line.

Example:
.banner {
    background: linear-gradient(to right, red, blue);
}

B. RADIAL GRADIENT
Spreads outward from a central point, usually in a circular or elliptical shape.

Example:
.circle {
    background: radial-gradient(circle, yellow, blue);
}

C. CONIC GRADIENT
Transitions between colors around a center point by angle.

Example:
.color-wheel {
    background: conic-gradient(red, yellow, green, blue, red);
}


11. CONIC GRADIENT IN DETAIL
----------------------------
WHAT:
A conic gradient transitions between colors around a center point. It can be
used to create color-wheel effects, pie-chart-style designs, and decorative
backgrounds.

SYNTAX:
background: conic-gradient(
    [from angle] [at position],
    color-stop1,
    color-stop2,
    ...
);

The square brackets in this syntax indicate optional parts. Do not type the
square brackets into the CSS declaration.

PARTS:
from angle -> Specifies the starting angle.
at position -> Specifies the center position.
color-stop -> Specifies a color and optionally its position.

EXAMPLE 1 - BASIC CONIC GRADIENT:
.gradient {
    width: 250px;
    height: 250px;
    background: conic-gradient(
        red,
        yellow,
        green,
        blue,
        red
    );
}

EXAMPLE 2 - STARTING ANGLE:
.gradient {
    background: conic-gradient(
        from 90deg,
        red,
        yellow,
        green,
        blue,
        red
    );
}

from 90deg rotates the starting angle of the gradient.

EXAMPLE 3 - CHANGING THE CENTER:
.gradient {
    background: conic-gradient(
        from 45deg at 30% 40%,
        red,
        yellow,
        blue,
        red
    );
}

The center is positioned at 30% of the element's width and 40% of its height.

EXAMPLE 4 - PIE-CHART EFFECT:
.pie-chart {
    width: 220px;
    height: 220px;
    border-radius: 50%;

    background: conic-gradient(
        #ef4444 0% 25%,
        #22c55e 25% 60%,
        #3b82f6 60% 100%
    );
}

The sections represent:
Red   -> 25%
Green -> 35%
Blue  -> 40%

EXAMPLE 5 - CONIC GRADIENT WITH HSL:
.color-wheel {
    width: 250px;
    height: 250px;
    border-radius: 50%;

    background: conic-gradient(
        hsl(0, 100%, 50%),
        hsl(60, 100%, 50%),
        hsl(120, 100%, 40%),
        hsl(180, 100%, 45%),
        hsl(240, 100%, 50%),
        hsl(300, 100%, 50%),
        hsl(360, 100%, 50%)
    );
}

DEVELOPER NOTE:
A conic gradient does not automatically contain every color at every angle.
The color stops you specify determine the transitions.


12. COMMON MISTAKES
-------------------
1. Writing #GG0000:
   Hexadecimal digits can only be 0-9 and A-F.

2. Writing rgb(256, 0, 0) in traditional numeric RGB:
   Use channel values between 0 and 255.

3. Assuming alpha starts at 0.1:
   Alpha ranges from 0 to 1, including both endpoints.

4. Assuming opacity: 0.5 affects only the background:
   It affects the entire element, including its children.

5. Confusing HSL saturation with lightness:
   Saturation controls vividness; lightness controls the light-to-dark level.

6. Thinking #RRGGBBAA ends with blue:
   The final two digits represent alpha. Blue is the preceding pair.

7. Confusing conic and linear gradients:
   A conic gradient transitions around a center point; a linear gradient
   transitions along a straight line.

14. QUICK INTERVIEW REVISION
----------------------------
Q1. What is RGB?
A. A color model that combines red, green, and blue channel intensities.

Q2. What is hexadecimal color notation?
A. A base-16 representation of color channels using digits 0-9 and letters A-F.

Q3. What is the difference between RGB and RGBA?
A. RGBA adds alpha to control the color's transparency.

Q4. What is HSL?
A. A color representation based on hue, saturation, and lightness.

Q5. What is the difference between HSL and HSLA?
A. HSLA adds an alpha channel.

Q6. What is the difference between opacity and alpha in a background color?
A. Element opacity affects the entire element. Background alpha affects only
   that background color layer.

Q7. What is a conic gradient?
A. A gradient that transitions between colors around a center point.

Q8. Can hexadecimal colors include transparency?
A. Yes. Use #RGBA or #RRGGBBAA.

Q9. Which color format is best?
A. No format is universally best. Choose based on readability, design
   requirements, and the project workflow.
